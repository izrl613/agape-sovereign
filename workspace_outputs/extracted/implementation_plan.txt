# Auth & Export Enhancement Plan

Three tightly connected features that improve the login experience and data-portability story.

---

## What We're Building

### 1. Dual Auth Paths — Passkey + Google (redesigned Login)
The login screen gets a **two-panel card** layout:

| Left card | Right card |
|---|---|
| 🔑 **Passkey / WebAuthn** | **G** Sign in with Google |
| "Device-bound · Local vault" | "Save reports to Google Drive" |

- Passkey path: email field → browser biometric / security key → signs in via existing `loginWithPasskey()` + `signInWithCustomToken`
- Google path: existing `loginWithGoogle()` OAuth popup/redirect
- Both paths are always visible side-by-side (no toggling)

### 2. Local Profile Vault vs. Google Drive — clarified save destinations
- **Passkey users** → reports save to **IndexedDB encrypted local vault** (`sovereign.nyc` origin) with a **26-month rolling window** of PDF DPCs
- **Google users** → reports optionally push to **Google Drive** (via `gapi`/Google Picker) in addition to local download
- When a user tries to export/save a DPC PDF, a **`SaveExportWarningModal`** appears explaining:
  - Where the file will be stored (device vault or Drive)
  - 26-month retention policy (Passkey vault)
  - Privacy reminder (no server storage, zero-knowledge)

### 3. Demo / Guest Bypass Button — always visible
- Remove `VITE_DEMO_MODE` flag gate from `DemoBypassButton`
- Button is **always rendered** on the Login page below both auth cards
- Styled prominently as "🚀 Explore as Guest" with a 30-min TTL disclaimer

## Files Changed

### NEW files

#### [NEW] `src/components/auth/SaveExportWarningModal.tsx`
Full-screen warning splash that appears before any PDF DPC export.
- Props: `authType`, `storageTarget ('local'|'drive'|'download')`, `onConfirm`, `onCancel`
- Shows vault location, 26-month retention, zero-knowledge reminder
- "Save to Device" vs "Save to Google Drive" action buttons (contextual to authType)

#### [NEW] `src/services/localVaultService.ts`
IndexedDB wrapper for the 26-month DPC archive:
- `saveReport(uid, pdfBlob, metadata)` — stores encrypted PDF + metadata
- `listReports(uid)` — returns list of stored reports (newest first)
- `pruneOldReports(uid)` — deletes anything older than 26 months
- `exportReport(id)` — retrieves blob for download

#### [NEW] `src/services/driveExportService.ts`
Google Drive upload via Google Identity Services + Drive REST API v3:
- `initDriveClient()` — lazy-loads `gapi` script
- `exportToDrive(pdfBlob, fileName)` — uploads to `Agape Sovereign/DPC Reports/` folder
- Only called for Google-authenticated users
