# AGAPE AI KIMI3 DRAFT — PWA Operation Framework Integration

## Overview

Integration of the Agape Sovereign PWA Operation Framework into the Android app
`com.agape.sovereign.ai`. This bridges the native Android privacy/security vault
with the PWA frontend (React/TypeScript) and the agent-based orchestration pipeline.

## Components

### 1. PWA WebView Screen (`PwaScreen.kt`)
- Loads PWA frontend from embedded server or remote URL
- Enables JavaScript, DOM storage, service workers
- Full-screen immersive mode

### 2. JavaScript Bridge (`PwaBridgeInterface.kt`)
- `getBiometricStatus()` — Biometric availability check
- `unlockWithBiometric()` — Trigger biometric authentication
- `getLocalData(key)` — Read from Room/SecureStorage
- `setLocalData(key, value)` — Write to Room/SecureStorage
- `getMcpServerUrl()` — Get in-app MCP server URL
- `getOllamaUrl()` — Get Ollama base URL
- `triggerPipeline(type)` — Trigger agent pipeline workflow

### 3. In-App MCP Server Extensions (`InAppMcpServer.kt`)
- `GET /android/pwa/*` — Serve PWA static assets
- `POST /android/run_pipeline` — Execute agent orchestration pipeline
- `POST /android/pwa/scan` — Trigger identity vector scan
- `POST /android/pwa/export` — Generate sovereign export

### 4. Agent Pipeline Integration
The Android app can trigger the Python agent pipeline via:
- Local subprocess (if Python runtime available on device)
- Remote call to the backend server
- Delegation to the InAppMcpServer which forwards to a backend
