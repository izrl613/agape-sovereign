Two bugs these shots caught. (1) overflow-x: hidden on the page wrapper turned it into a scroll container, which silently killed position: sticky — the header and the whole nav scrolled away. Replaced with overflow-x: clip. (2) The print stylesheet was overriding body colours but not -webkit-text-fill-color, so the H1, lead paragraph, chips and fact table printed near-white on white.
